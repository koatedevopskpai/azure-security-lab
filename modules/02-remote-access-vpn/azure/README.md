# SDCI Lab 02 — Remote Access VPN (Azure)

**SDCI 300-745 Domain**: Internet Edge security & VPN connectivity

## Overview

Deploy an Azure VPN Gateway with Point-to-Site (P2S) configuration. Remote users connect using native VPN clients to access workloads in a private subnet.

Azure VPN Gateway (VpnGw1) costs ~$0.03/hour. **Not free tier eligible.** Destroy immediately after use. A 2-hour session costs ~$0.06.
